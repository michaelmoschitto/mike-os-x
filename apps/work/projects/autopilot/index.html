Autopilot — Project Info

Autopilot

What is it?

Autopilot applies AI browser automation to testing and operational workflows. Teams can build an agent, run it against a real product, and keep track of how the workflow changes over time.

My role

I shipped features across Autopilot’s entire stack, from the infrastructure that runs agents to the workflows people use every day. I designed and delivered many of its core interactions. The command palette, version history, and agent builder are three favorites because they make a powerful system easier to navigate, inspect, and control.
